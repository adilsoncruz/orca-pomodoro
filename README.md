# Pomodoro Focus for Orca

A simple Pomodoro timer panel for the Orca IDE.

## Features

- 25-minute focus timer with configurable focus and break durations
- Start, pause, reset, and skip controls
- Completed-session counter
- Notification sound when a phase changes

## Install in Orca

1. Open **Settings → Plugins → Marketplaces**.
2. Add this repository URL:
   `https://github.com/adilsoncruz/orca-pomodoro`
3. Install **Pomodoro Focus** and enable the plugin.

The plugin system is experimental in Orca. Review third-party plugin code before enabling it.
